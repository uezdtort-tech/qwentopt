# Conditera Next — Экосистема для кондитеров

## О проекте

Conditera Next — современная веб-платформа для кондитеров, объединяющая маркетплейс, рабочее место кондитера, B2B-раздел, планировщик мероприятий и AI-помощник.

## Текущий статус реализации

### ✅ Социальная авторизация (Яндекс ID + VK ID)

Реализована полноценная интеграция OAuth 2.0 с PKCE:
- ✅ Кнопки «Войти через Яндекс ID» и «Войти через VK ID» с официальными логотипами
- ✅ Безопасный OAuth flow с PKCE (S256)
- ✅ State parameter для защиты от CSRF
- ✅ Валидация redirect URI по allowlist
- ✅ Обработка ошибок и edge cases
- ✅ Страница callback с визуализацией статуса
- ✅ Защита от повторного запуска OAuth
- ✅ Сохранение returnUrl для защищённых разделов
- ✅ Демо-режим без Supabase
- ✅ Документация по настройке провайдеров
- ⚠️ Token exchange на клиенте (в production перенести на сервер)
- ⚠️ Связывание аккаунтов требует Supabase

Подробнее: [docs/OAUTH_SETUP.md](docs/OAUTH_SETUP.md)

### ✅ Уровень 1 — UI Prototype (реализовано)

- **Главная страница** — полноценный коммерческий лендинг с поиском, категориями, подборкой товаров, CTA для кондитеров
- **Каталог** — фильтрация по категории, цене, поиск, сортировка, сохранение параметров в URL
- **Карточка товара** — полная информация, аллергены, характеристики, добавление в корзину
- **Кабинет кондитера:**
  - Обзор (Dashboard) — статистика, приоритетные задачи, дефицит ингредиентов
  - Заказы — полный жизненный цикл: new → accepted → in_production → ready → completed
  - Товары — CRUD с публикацией/скрытием
  - Рецепты — редактор с ингредиентами, расчёт себестоимости
  - Склад — остатки, минимальные уровни, дефицит, операции
  - Покупатели — CRM с контактами и историей
  - Финансы — выручка, комиссии, история операций
- **B2B** — каталог партнёров по категориям, поиск
- **Event Planner** — мероприятия с задачами и прогрессом
- **Чат** — обмен сообщениями с визуализацией статусов
- **AI-помощник** — демо-интерфейс с подсказками (Ollama не подключена)
- **Авторизация** — UI входа/регистрации с выбором роли
- **Корзина** — добавление/удаление товаров, итоговая сумма
- **Дизайн-система** — кремовый фон, ягодный акцент, типографика Inter + Playfair Display

## Что требует настройки для production

1. **Supabase** — создать таблицы, настроить RLS, миграции
2. **Supabase Auth** — настроить провайдеров аутентификации
3. **Supabase Storage** — создать бакеты для изображений
4. **Ollama** — установить и запустить локально, настроить URL
5. **n8n** — настроить webhook-воркфлоу
6. **Платёжный провайдер** — подключить адаптер (ЮKassa, Stripe)
7. **Docker** — создать Dockerfile и compose.yaml
8. **Reverse proxy** — настроить Caddy/Nginx с HTTPS
9. **DNS** — направить conditera.ru на публичный IP

## Известные ограничения

- Данные демонстрационные, не сохраняются между сессиями
- Авторизация имитируется без реальной проверки
- AI-помощник работает в демо-режиме без Ollama
- Платежи не реализованы (нет платёжного провайдера)
- Загрузка файлов не реализована (нет Supabase Storage)
- Real-time чат не реализован (нет WebSocket)

## Безопасность (рекомендации для production)

- Все бизнес-правила на сервере (Supabase RLS + Edge Functions)
- Service-role ключ никогда не передаётся в браузер
- Валидация входных данных на сервере
- Rate limiting для чувствительных операций
- CORS ограничен доменом conditera.ru
- HTTPS обязательно
- Секреты в переменных окружения, не в коде
