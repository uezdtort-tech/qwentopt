## 🔌 Интеграции с внешними сервисами

Реализована модульная архитектура адаптеров для 8 внешних сервисов:

### ✅ Реализованные интеграции (5)

1. **YooKassa** — Платежная система (IMPLEMENTED, local mode)
   - Создание платежей с идемпотентностью
   - Обработка webhook уведомлений
   - Возвраты (полные и частичные)
   - Локальный тестовый режим

2. **Яндекс ID** — OAuth 2.0 с PKCE (IMPLEMENTED, local mode)
   - Авторизация через Яндекс
   - Защита от CSRF
   - Тестовый пользователь

3. **VK ID** — OAuth 2.0 с PKCE (IMPLEMENTED, local mode)
   - Авторизация через VK
   - Защита от CSRF
   - Тестовый пользователь

4. **SMTP** — Email уведомления (IMPLEMENTED, local mode)
   - Очередь писем
   - Повторные попытки
   - Локальная имитация

5. **Telegram** — Уведомления (IMPLEMENTED, local mode)
   - Отправка сообщений
   - Проверка соединения
   - Локальная имитация

### ⚠️ Требуют настройки (3)

6. **Supabase** — База данных (NOT_CONFIGURED)
7. **Ollama** — AI помощник (NOT_CONFIGURED)
8. **n8n** — Автоматизация (NOT_CONFIGURED)
