# Conditera Next — Маркетплейс для кондитеров

Работающий маркетплейс тортов и десертов с кабинетом кондитера.

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Открыть в браузере
# http://localhost:3000
```

## Страницы

- **Главная** (`/`) — hero-секция, популярные товары, преимущества
- **Каталог** (`/catalog`) — список всех товаров с поиском
- **Карточка товара** (`/product/:id`) — детальная информация о товаре
- **Кабинет кондитера** (`/dashboard`) — статистика и заказы
- **Авторизация** (`/auth`) — вход через email или соцсети

## Технологии

- React 18 + TypeScript
- Vite
- Tailwind CSS 4
- React Router DOM 6

## Структура

```
src/
├── App.tsx              # Главный компонент с роутингом
├── data/
│   └── products.ts      # Mock-данные товаров
└── index.css            # Стили Tailwind
```

## Сборка

```bash
npm run build
# Результат в dist/
```

## Особенности

- ✅ Адаптивный дизайн (mobile-first)
- ✅ Стандартные цвета Tailwind CSS
- ✅ Работающая навигация между страницами
- ✅ Карточки товаров с изображениями
- ✅ Кабинет кондитера со статистикой
