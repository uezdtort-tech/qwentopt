# Conditera Next — Цифровая экосистема для кондитеров

Полноценный frontend маркетплейса и рабочей платформы для кондитеров с persistence через localStorage.

## 🎯 Что реализовано

### ✅ Полностью работающие модули

#### Публичная часть
- **Главная страница** — hero-секция, направления экосистемы, популярные товары, преимущества, CTA для кондитеров
- **Каталог** — поиск, фильтры по категориям, сортировка, карточки товаров
- **Карточка товара** — полная информация, аллергены, характеристики, добавление в корзину, связь с продавцом
- **Конструктор торта** — 5-шаговый интерактивный конструктор с автоматическим расчётом стоимости:
  - Выбор категории (торт, капкейки, макаруны и др.)
  - Форма и размер
  - Коржи, начинка, крем, покрытие
  - Декор, надписи
  - Дата доставки, комментарии
  - Расчёт стоимости на основе параметров
  - Сохранение проекта
- **Корзина** — добавление/удаление товаров, оформление заказа с датой доставки
- **Чат** — обмен сообщениями с кондитером, история сохраняется
- **Мероприятия** — создание событий, задачи, прогресс
- **B2B** — каталог поставщиков и магазинов декора
- **Авторизация** — вход/регистрация с выбором роли, быстрый вход для демо

#### Кабинет кондитера
- **Обзор** — статистика (новые заказы, в производстве, выручка, товары), дефицит ингредиентов
- **Заказы** — полный жизненный цикл: `new → accepted → in_production → ready → completed`
- **Товары** — добавление новых товаров, таблица с категориями и статусами
- **Рецептуры** — создание рецептов, расчёт себестоимости
- **Склад** — остатки, предупреждения о дефиците, поступление/списание
- **Финансы** — выручка, комиссии, к выплате
- **Клиенты** — CRM с историей заказов
- **Производство** — календарь активных заказов

#### Кабинет клиента
- **Обзор** — статистика заказов
- **Мои заказы** — история с статусами
- **Избранное** — (заготовка)
- **Профиль** — (заготовка)

#### Кабинет администратора
- **Обзор** — статистика платформы
- **Пользователи** — таблица всех пользователей с ролями
- **Все заказы** — управление всеми заказами
- **Модерация** — (заготовка)
- **Аналитика** — (заготовка)

#### Другие роли
- **Поставщик** — кабинет с товарами и заказами
- **Организатор** — управление мероприятиями
- **Аниматор** — бронирования и финансы
- **Декоратор** — товары и заказы

### ✅ Persistence данных

Все данные сохраняются в `localStorage`:
- Пользователи, товары, заказы, рецепты, склад
- Сообщения чата
- Мероприятия и задачи
- Корзина
- Проекты конструктора

При перезагрузке страницы все данные восстанавливаются.

### ✅ Ролевая модель

Поддерживаются 12 ролей:
- `client` — клиент
- `confectioner` — кондитер
- `supplier` — поставщик
- `decorator` — магазин декора
- `animator` — аниматор
- `organizer` — организатор мероприятий
- `operator` — оператор
- `support` — поддержка
- `moderator` — модератор
- `admin` — администратор
- `superadmin` — владелец платформы
- `guest` — гость

Каждая роль имеет:
- Собственный интерфейс кабинета
- Доступ к определённым разделам
- Видимые данные (только свои или все для админа)

## ⚠️ Что НЕ реализовано (требует backend)

### Критические компоненты

1. **Backend API**
   - Нет серверной логики
   - Нет REST API endpoints
   - Нет middleware для авторизации

2. **База данных**
   - Нет Supabase/PostgreSQL
   - Нет миграций
   - Нет RLS (Row Level Security)

3. **Реальная авторизация**
   - Нет проверки учётных данных
   - Нет JWT/сессий
   - Пароли не хэшируются
   - OAuth (Яндекс ID, VK ID) — только UI

4. **Реальные платежи**
   - Нет интеграции с платёжным провайдером
   - Нет обработки транзакций
   - Нет возвратов

5. **Загрузка файлов**
   - Нет Supabase Storage
   - Нет загрузки изображений товаров
   - Используются эмодзи вместо фото

6. **Real-time**
   - Чаты не синхронизируются между пользователями
   - Нет WebSocket
   - Нет push-уведомлений

7. **Интеграции**
   - Ollama (AI-помощник) — не подключена
   - n8n (автоматизация) — не подключена
   - Платёжный провайдер — отсутствует

8. **Инфраструктура**
   - Нет Docker-конфигурации
   - Нет reverse proxy
   - Нет HTTPS
   - Нет мониторинга

### Ограничения текущего решения

**localStorage:**
- Данные хранятся только в браузере пользователя
- Нет синхронизации между устройствами
- Нет резервного копирования
- Ограниченный объём (~5-10 MB)
- Данные теряются при очистке браузера

**Безопасность:**
- Нет серверной валидации
- Нет защиты от IDOR
- Нет rate limiting
- Роли можно изменить в localStorage
- Нет аудита действий

**Масштабируемость:**
- Нет разделения на frontend/backend
- Нет кэширования
- Нет оптимизации запросов
- Нет CDN для статики

## 🎯 Следующие шаги для production

### Приоритет 1: Backend и БД
1. Разработать API на Node.js/Express или использовать Supabase Edge Functions
2. Подключить Supabase PostgreSQL
3. Создать миграции для всех таблиц
4. Настроить RLS policies
5. Реализовать серверную валидацию

### Приоритет 2: Авторизация
1. Интегрировать Supabase Auth
2. Реализовать OAuth (Яндекс ID, VK ID)
3. Настроить JWT/сессии
4. Добавить хэширование паролей

### Приоритет 3: Интеграции
1. Подключить Ollama для AI-помощника
2. Настроить n8n для автоматизации
3. Интегрировать платёжный провайдер (ЮKassa, Stripe)
4. Подключить Supabase Storage для изображений

### Приоритет 4: Инфраструктура
1. Создать Dockerfile и docker-compose.yaml
2. Настроить reverse proxy (Caddy/Nginx)
3. Настроить HTTPS
4. Настроить мониторинг и логи
5. Настроить backup/restore

### Приоритет 5: Тестирование
1. Написать unit-тесты
2. Написать интеграционные тесты
3. Написать E2E тесты
4. Провести аудит безопасности
5. Провести нагрузочное тестирование

## 📝 Использование

### Регистрация нового пользователя
1. Перейти на `/auth`
2. Выбрать "Регистрация"
3. Заполнить имя, email, пароль
4. Выбрать роль
5. Нажать "Создать аккаунт"

### Быстрый вход (демо)
На странице `/auth` есть кнопки быстрого входа:
- 👤 Клиент (maria@mail.ru)
- 🎂 Кондитер (anna@conditera.ru)
- 📦 Поставщик (supplier@moloko.ru)
- 🛡️ Админ (admin@conditera.ru)

### Создание товара (кондитер)
1. Войти как кондитер
2. Перейти в "Кабинет" → "Товары"
3. Нажать "Добавить"
4. Заполнить форму
5. Нажать "Сохранить"

### Оформление заказа (клиент)
1. Войти как клиент
2. Перейти в "Каталог"
3. Выбрать товар
4. Нажать "В корзину"
5. Перейти в "Корзина"
6. Указать дату доставки
7. Нажать "Оформить заказ"

### Создание проекта конструктора
1. Перейти на `/constructor`
2. Пройти 5 шагов:
   - Категория
   - Размер
   - Начинка
   - Декор
   - Детали
3. Увидеть расчёт стоимости
4. Нажать "Сохранить проект"
