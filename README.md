## ⚠️ Что НЕ реализовано (требует backend)

### Критические компоненты

1. **Backend API**
   - ❌ Нет серверной логики
   - ❌ Нет REST API endpoints
   - ❌ Нет middleware для авторизации

2. **База данных**
   - ❌ Нет Supabase/PostgreSQL
   - ❌ Нет миграций
   - ❌ Нет RLS (Row Level Security)

3. **Реальная авторизация**
   - ❌ Нет проверки учётных данных
   - ❌ Нет JWT/сессий
   - ❌ OAuth (Яндекс ID, VK ID) — только UI

4. **Реальные платежи**
   - ❌ Нет интеграции с платёжным провайдером
   - ❌ Нет обработки транзакций

5. **Загрузка файлов**
   - ❌ Нет Supabase Storage
   - ❌ Используются эмодзи вместо реальных фото

6. **Real-time**
   - ❌ Чаты не синхронизируются между пользователями
   - ❌ Нет WebSocket

7. **Интеграции**
   - ❌ Ollama (AI-помощник) — не подключена
   - ❌ n8n (автоматизация) — не подключена

8. **Инфраструктура**
   - ❌ Нет Docker-конфигурации
   - ❌ Нет reverse proxy
   - ❌ Нет HTTPS

4. Нажать "В корзину"
5. Перейти в "Корзина"
6. Указать дату доставки
7. Нажать "Оформить заказ"

### Создание проекта конструктора
1. Перейти на `/constructor`
2. Пройти 5 шагов:
   - Категория
   - Размер
   - Начинка
   - Декор
   - Детали
3. Увидеть расчёт стоимости
4. Нажать "Сохранить проект"
5. Найти проект в "Мои проекты"

### Управление заказом (кондитер)
1. Войти как кондитер
2. Перейти в "Кабинет" → "Заказы"
3. Найти заказ
4. Нажать "Принять" → статус меняется на "accepted"
5. Нажать "Начать готовить" → статус "in_production"
6. Нажать "Готов" → статус "ready"
7. Нажать "Выдан" → статус "completed"

### Создание мероприятия
1. Войти как организатор
2. Перейти на `/events`
3. Нажать "Создать"
4. Заполнить форму (название, дата, место, бюджет)
5. Нажать "Создать"
6. Добавить задачи и назначить исполнителей
