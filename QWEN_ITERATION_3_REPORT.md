## 🎯 Как проверить

### Запустить приложение

```bash
npm run dev
```

### Проверить B2B Marketplace

```
http://localhost:3000/b2b-marketplace
```

**Что проверить:**

1. **Контактный запрос:**
   - Перейти на вкладку "Поставщики"
   - Нажать "Связаться" на любом поставщике
   - Заполнить форму с некорректными данными — проверить валидацию
   - Заполнить форму корректно и отправить
   - Проверить появление запроса в списке "Мои запросы"

2. **Закупочный запрос:**
   - Перейти на вкладку "Товары"
   - Нажать "Заказать" на любом товаре
   - Ввести количество меньше минимального — проверить валидацию
   - Ввести корректное количество
   - Проверить автоматический расчёт стоимости
   - Отправить запрос
   - Проверить появление запроса в списке "Мои запросы"

3. **DEMO обозначение:**
   - Проверить наличие жёлтого баннера в начале страницы
   - Проверить пометки "DEMO" в списках запросов

4. **Сохранение данных:**
   - Создать несколько запросов
   - Перезагрузить страницу
   - Проверить, что запросы сохранились

### Проверить Visual Constructor V2

http://localhost:3000/visual-constructor-v2

## ⚠️ Известные проблемы

### 1. Проблемы с типами тестов

**Описание:**
- Тесты для Visual Constructor V2 имеют ошибки типизации
- @testing-library/jest-dom не экспортирует типы правильно для vitest

**Влияние:**
- Тесты можно запустить, но некоторые проверки типов не проходят
- Не блокирует работу приложения

**Решение:**
- Установлен @types/testing-library__jest-dom
- Требуется дополнительная настройка или обновление пакетов

### 2. Все модули используют mock-данные

**Описание:**
- Все 8 модулей используют localStorage или захардкоженные данные
- Нет интеграции с реальной БД
- Нет серверной валидации

**Влияние:**
- Данные не синхронизируются между устройствами
- Нет резервного копирования
- Нет защиты от модификации пользователем

**Решение:**
- Требуется интеграция с backend
- Требуется настройка Supabase или другой БД
