# Repository Convergence Plan — План безопасного объединения

**Дата:** 2026-01-15  
**Статус:** Предварительный план (требует доступа к Conditera)

## 1. Стратегия объединения

### Основной принцип

**Сохранить Conditera как основу продукта. Переносить из Qwentopt только проверенные UI-улучшения.**

### Обоснование

1. **Conditera (предположительно)** содержит:
   - Реальную бизнес-логику
   - Интеграцию с Supabase
   - Серверную валидацию
   - Тесты
   - Production-конфигурацию

2. **Qwentopt (фактически)** содержит:
   - Только UI-прототип
   - Mock-данные
   - Клиентскую бизнес-логику (небезопасно)
   - Отсутствие интеграций

3. **Риск полной замены:**
   - Потеря реальной бизнес-логики
   - Потеря интеграций
   - Потеря безопасности
   - Потеря тестов
   - Откат к уровню UI-прототипа
