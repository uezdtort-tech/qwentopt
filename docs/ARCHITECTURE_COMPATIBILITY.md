### Архитектурные решения

#### 1. Состояние приложения

**Решение:** React Context + localStorage

**Плюсы:**
- ✅ Простота реализации
- ✅ Нет необходимости в backend
- ✅ Быстрый старт
- ✅ Работает offline

**Минусы:**
- ❌ Данные только в браузере пользователя
- ❌ Нет синхронизации между устройствами
- ❌ Нет резервного копирования
- ❌ Ограниченный объём (~5-10 MB)
- ❌ Нет защиты от модификации

**Код:**
```typescript
// src/store.ts
export function loadStore(): Store {
  try {
    const raw = localStorage.getItem(STORAGE_KEY);
    if (raw) return JSON.parse(raw);
  } catch {}
  return defaultData;
}

export function saveStore(store: Store) {
  try { localStorage.setItem(STORAGE_KEY, JSON.stringify(store)); } catch {}
}
```

#### 2. Роутинг

**Решение:** React Router DOM 6 с HashRouter

**Плюсы:**
- ✅ Работает без серверной настройки
- ✅ Поддерживается статическими хостингами
- ✅ Простота использования

**Минусы:**
- ❌ URL с # (не SEO-friendly)
- ❌ Нет server-side rendering

**Код:**
```typescript
// src/App.tsx
<HashRouter>
  <Routes>
    <Route path="/" element={<HomePage />} />
    <Route path="/catalog" element={<CatalogPage />} />
    <Route path="/dashboard/*" element={<DashboardLayout />} />
  </Routes>
</HashRouter>
```

### Проблемы совместимости

#### 1. Состояние приложения

**qwentopt:** React Context + localStorage  
**Conditera (предположительно):** Supabase + React Query/SWR

**Проблема:**
- ❌ Разные подходы к управлению состоянием
- ❌ localStorage не совместим с серверным состоянием
- ❌ Нет синхронизации

**Решение:**
- ⚠️ Заменить localStorage на Supabase queries
- ⚠️ Использовать React Query/SWR для кэширования
- ⚠️ Мигрировать данные из localStorage в Supabase

**Риски:**
- 🔴 Высокие — требуется полная переделка управления состоянием

#### 2. Роутинг

**qwentopt:** HashRouter  
**Conditera (предположительно):** BrowserRouter или Next.js routing

**Проблема:**
- ❌ HashRouter не SEO-friendly
- ❌ Нет server-side rendering

**Решение:**
- ⚠️ Заменить HashRouter на BrowserRouter
- ⚠️ Настроить server-side routing
- ⚠️ Обновить все ссылки

**Риски:**
- 🟡 Средние — требуется настройка сервера

#### 3. Интеграции

**qwentopt:** Адаптеры с local mode  
**Conditera (предположительно):** Production интеграции

**Проблема:**
- ❌ Адаптеры qwentopt в local mode
- ❌ Нет production credentials
- ❌ Нет реальной обработки

**Решение:**
- ✅ Использовать архитектуру адаптеров из qwentopt
- ✅ Добавить production credentials
- ✅ Реализовать серверную обработку

**Риски:**
- 🟢 Низкие — архитектура адаптеров хорошая

#### 4. Ролевая модель

**qwentopt:** 18 ролей в localStorage  
**Conditera (предположительно):** Роли в Supabase с RLS

**Проблема:**
- ❌ Роли в localStorage можно изменить
- ❌ Нет серверной проверки прав
- ❌ Нет RLS

**Решение:**
- ✅ Использовать ролевую модель из qwentopt
- ⚠️ Мигрировать роли в Supabase
- ⚠️ Настроить RLS policies

**Риски:**
- 🟡 Средние — требуется настройка RLS

#### 5. Типы данных

**qwentopt:** TypeScript типы  
**Conditera (предположительно):** TypeScript типы + Supabase типы

**Проблема:**
- ❌ Типы qwentopt не связаны с Supabase схемой
- ❌ Нет автоматической генерации типов

**Решение:**
- ⚠️ Синхронизировать типы с Supabase схемой
- ⚠️ Использовать Supabase CLI для генерации типов
- ⚠️ Обновить все компоненты

**Риски:**
- 🟡 Средние — требуется синхронизация типов
