### 2. Какие улучшения Qwentopt действительно стоит сохранить?

**Ответ:** Только UI-компоненты и UX-паттерны, не затрагивающие бизнес-логику.

#### ✅ Безопасно переносить:

**A. Дизайн-система**
- Цветовая палитра (cream, graphite, berry, sage, gold, lavender)
- Типографика (Inter + Playfair Display)
- Анимации и переходы
- Стили скроллбара

**B. Структура Layout**
- Компонент `Header` с адаптивным меню
- Компонент `DashboardSidebar` с иконками
- Компонент `Footer` с навигацией

**C. OAuth UI**
- Компонент `SocialAuthButton` с официальными логотипами
- Страница `AuthCallbackPage` с обработкой ошибок
- Стили кнопок (Яндекс ID, VK ID)

**D. UX-паттерны каталога**
- Сохранение фильтров в URL (`useSearchParams`)
- Ползунок цены
- Сортировка
- Адаптивная сетка карточек

**E. Структура кабинета кондитера**
- Структура бокового меню
- Карточки статистики
- Таблицы с действиями
- Пустые состояния

#### ❌ НЕ переносить:

**A. Mock-данные**
- Захардкоженные товары, заказы, пользователи
- Не соответствуют реальной бизнес-логике

**B. Клиентская бизнес-логика**
- `AppContext.tsx` с имитацией авторизации
- Клиентское управление заказами, товарами, складом
- Отсутствие серверной валидации

**C. Страницы без реальной функциональности**
- Формы, которые не сохраняют данные
- Чат без real-time
- Финансы без реальных платежей

**D. OAuth Service (в текущем виде)**
- Token exchange на клиенте (небезопасно)
- Требует адаптации под Supabase Auth
- Необходимо перенести на сервер
